# Loglama və SIEM (Security Information and Event Management)

Bu layihə informasiya təhlükəsizliyində loglama və SIEM anlayışlarını əhatə edir.  
Layihənin məqsədi — SIEM sistemlərinin iş prinsiplərini, log korelyasiyasını, xəbərdarlıqların yaradılmasını və açıq mənbə SIEM alətlərinin təhlilini təqdim etməkdir.

## 🔍 Mündəricat
- Loglama nədir?
- SIEM nədir?
- Loglama və SIEM arasındakı fərqlər
- SIEM-in əsas funksiyaları
- Açıq mənbə SIEM alətləri (Wazuh, Elastic, OSSEC, Graylog, Security Onion)
- SIEM-in üstünlükləri və çətinlikləri
- Nəticə
